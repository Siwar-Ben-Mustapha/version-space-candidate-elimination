The notebook

Notebook syntax 
attribute Name : value1, value2, value3
attribute Size : interval 0 .. inf step 1
attribute Colour : russet, orange, grey
  group warm : russet, orange
+ value1, 30, russet     positive example
- value2, 70, grey       negative example
? in an example = missing value

A categorical attribute accepts a value or “?”. A group adds an intermediate constraint (like “warm colour” in the course). A numeric attribute is described by a grid; its constraints are intervals [low, high]. The French keywords (attribut, groupe, intervalle, pas) are also accepted.
