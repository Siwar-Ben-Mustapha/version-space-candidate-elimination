Le carnet

Syntaxe du carnet 
attribut Nom : valeur1, valeur2, valeur3
attribut Taille : intervalle 0 .. inf pas 1
attribut Couleur : roux, orange, gris
  groupe chaude : roux, orange
+ valeur1, 30, roux      exemple positif
- valeur2, 70, gris      exemple négatif
? dans un exemple = valeur manquante

Un attribut catégoriel accepte une valeur ou « ? ». Un groupe ajoute une contrainte intermédiaire (comme « couleur chaude » dans le cours). Un attribut numérique se décrit par une grille ; ses contraintes sont des intervalles [bas, haut].
